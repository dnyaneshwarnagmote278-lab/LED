Arduino Port Setup (serial)

  1. Upload the sketch below with Arduino IDE (Board: Arduino UNO, choose the COM port / /dev/ttyACM0).
  2. Close Arduino IDE Serial Monitor — only one program can use the port.
  3. Click Connect Arduino on the dashboard, pick the port (e.g. “Arduino Uno (COM3)”) and press Connect.
  4. Baud rate: 9600. The page sends one byte: bit0 = LED1 … bit4 = LED5.
const int LED_PINS[5] = {2, 3, 4, 5, 6};
void setup() {
  Serial.begin(9600);
  for (int i = 0; i < 5; i++) { pinMode(LED_PINS[i], OUTPUT); digitalWrite(LED_PINS[i], LOW); }
}
void loop() {
  if (Serial.available() > 0) {
    int mask = Serial.read();
    for (int i = 0; i < 5; i++) digitalWrite(LED_PINS[i], (mask >> i) & 1);
  }
}

Components Used

  • Arduino UNO + USB cable
  • 5 × LEDs
  • 5 × 270Ω resistors
  • Breadboard + jumper wires
  • Laptop with webcam

How It Works

  1. The webcam streams video into the browser.
  2. MediaPipe Hands finds 21 landmarks on your hand.
  3. Each finger is “up” if its tip is farther from the wrist than its middle joint; the thumb is checked sideways.
  4. The count (0–5) is stabilised over a few frames, then looked up in the Gesture Mapping.
  5. The LED pattern is sent as one byte over USB serial; the Arduino switches D2–D6.
